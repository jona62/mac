# Enums Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `enum` keyword for exhaustive sum types with match destructuring, enabling Result/Option patterns and user-defined algebraic data types.

**Architecture:** Enum declarations create constructor functions in the environment. Enum values are a new `MacEnum` type in the `MacValue` variant. Match arms gain variant pattern syntax (`Enum.Variant(binding)`) that destructures into scoped bindings. The analyzer checks exhaustiveness when matching on enum values.

**Tech Stack:** C++23, Mac language interpreter

```cpp
#ifndef MAC_ENUM_H
#define MAC_ENUM_H

#include <memory>               // shared_ptr
#include <sstream>              // ostringstream (toString)
#include <string>               // string
#include <vector>               // vector (fields, variant defs)

namespace enumeration {

    // Definition of a single variant within an enum
    struct VariantDef {
        std::string name;
        std::vector<std::string> fields; // empty for simple variants
    };

    // Definition of an enum type (shared across all instances)
    struct MacEnumDef {
        std::string name; // e.g. "Result", "Color"
        std::vector<VariantDef> variants;

        bool hasVariant(const std::string& variantName) const {
            for (auto& v : variants) {
                if (v.name == variantName) return true;
            }
            return false;
        }

        const VariantDef* getVariant(const std::string& variantName) const {
            for (auto& v : variants) {
                if (v.name == variantName) return &v;
            }
            return nullptr;
        }
    };

    // An instance of an enum variant (runtime value)
    class MacEnum {
    public:
        std::shared_ptr<MacEnumDef> def; // shared enum definition
        std::string tag;                  // variant name, e.g. "Ok"
        std::vector<std::shared_ptr<void>> fields; // will store MacValue via type erasure

        // We store fields as a separate vector of MacValue
        // (defined after MacValue exists — see implementation note)

        std::string toString() const {
            std::ostringstream ss;
            ss << tag;
            if (!fieldValues.empty()) {
                ss << "(";
                for (size_t i = 0; i < fieldValues.size(); i++) {
                    if (i > 0) ss << ", ";
                    ss << fieldStr(i);
                }
                ss << ")";
            }
            return ss.str();
        }

        // Field values stored as strings for now — replaced with MacValue in Task 3
        std::vector<std::string> fieldValues;
        std::string fieldStr(size_t i) const {
            return i < fieldValues.size() ? fieldValues[i] : "";
        }
    };

} // namespace enumeration

#endif // MAC_ENUM_H
```

Wait — there's a circular dependency issue. `MacEnum` needs to store `MacValue` fields, but `MacValue` contains `MacEnum`. The solution: `MacEnum` stores field values in a `std::vector` of the variant type itself. Since `MacValue` is a variant and we're adding `MacEnum` to it, we need forward declarations.

Let me redesign this more carefully. The cleanest approach: `MacEnum` doesn't include `MacValue.h`. Instead, it stores field values as `std::any` or we use a simple forward-declared approach.

Actually, the simplest approach used by the existing codebase: forward declare in `MacValue.h`, define the class in its own header, and include the full definition only where needed (like how `MacMeme`, `MacGif` etc. work — they're forward-declared in `MacValue.h` and defined in their own headers).

```cpp
template <typename T>
shared_ptr<stmt::Stmt<T>> Parser::enumDeclaration() {
    Token keyword = previous();
    consume(TokenType::IDENTIFIER, "Expected enum name.");
    Token name = previous();
    consume(TokenType::LEFT_BRACE, "Expected '{' after enum name.");

    std::vector<typename stmt::EnumStmt<T>::Variant> variants;
    while (peek().type != TokenType::RIGHT_BRACE && !isAtEnd()) {
        consume(TokenType::IDENTIFIER, "Expected variant name.");
        Token variantName = previous();
        std::vector<Token> fields;
        if (match(TokenType::LEFT_PAREN)) {
            do {
                consume(TokenType::IDENTIFIER, "Expected field name.");
                fields.push_back(previous());
            } while (match(TokenType::COMMA));
            consume(TokenType::RIGHT_PAREN, "Expected ')' after variant fields.");
        }
        variants.push_back({variantName, std::move(fields)});
        match(TokenType::COMMA); // optional comma between variants
    }
    consume(TokenType::RIGHT_BRACE, "Expected '}' after enum variants.");

    return make_shared<stmt::EnumStmt<T>>(keyword, name, std::move(variants));
}
```

### Task 3: Interpreter — enum declaration and variant construction

- [ ] **Step 1: Implement visitEnumStmt**

When an `enum` declaration is evaluated, it should:
1. Create a `MacEnumDef` with all variant definitions
2. For each variant, register a constructor function in the environment under `EnumName.VariantName`
3. Register the enum definition itself for type checking

The approach: store enum definitions in a map on the interpreter. For each variant, create a callable that constructs `MacEnum` instances.

In `include/Interpreter.h`, add to the Interpreter class:
```cpp

```

Add `#include "MacEnum.h"` at the top.

Implement `visitEnumStmt`:
```cpp
void visitEnumStmt(stmt::EnumStmt<MacValue>* stmt) override {
    auto enumName = std::get<std::string>(stmt->name.lexeme);
    auto def = std::make_shared<enumeration::MacEnumDef>();
    def->name = enumName;

    for (auto& variant : stmt->variants) {
        auto variantName = std::get<std::string>(variant.name.lexeme);
        std::vector<std::string> fieldNames;
        for (auto& f : variant.fields)
            fieldNames.push_back(std::get<std::string>(f.lexeme));
        def->variants.push_back({variantName, fieldNames});
    }

    enumDefs[enumName] = def;

    // Create a map-like namespace object for Enum.Variant access
    auto enumMap = std::make_shared<collection::MacMap>();
    for (auto& vdef : def->variants) {
        if (vdef.fields.empty()) {
            // Simple variant — store as a MacEnum value directly
            auto inst = std::make_shared<enumeration::MacEnum>();
            inst->def = def;
            inst->tag = vdef.name;
            enumMap->set(vdef.name, MacValue(inst));
        } else {
            // Data variant — store a constructor callable
            auto constructor = std::make_shared<callable::EnumConstructor>(def, vdef.name, vdef.fields);
            enumMap->set(vdef.name, MacValue(std::static_pointer_cast<callable::MacCallable>(constructor)));
        }
    }
    env->define(enumName, MacValue(enumMap));
}
```

- [ ] **Step 3: Extend interpreter match for enum destructuring**

In `include/Interpreter.h`, `visitMatchExpr()`:

```cpp
MacValue visitMatchExpr(expr::MatchExpr<MacValue>* expr) override {
    auto subject = evaluate(expr->subject);

    for (auto& arm : expr->arms) {
        if (!arm.pattern) {
            return evaluate(arm.result);
        }

        // Check for enum variant pattern (Get expression = Enum.Variant)
        if (!arm.bindings.empty() || dynamic_cast<expr::Get<MacValue>*>(arm.pattern.get())) {
            // Try to match as enum variant
            if (std::holds_alternative<std::shared_ptr<enumeration::MacEnum>>(subject)) {
                auto subjectEnum = std::get<std::shared_ptr<enumeration::MacEnum>>(subject);
                auto patternVal = evaluate(arm.pattern);

                bool matches = false;
                if (std::holds_alternative<std::shared_ptr<enumeration::MacEnum>>(patternVal)) {
                    // Simple variant (no fields) — check tag match
                    auto patEnum = std::get<std::shared_ptr<enumeration::MacEnum>>(patternVal);
                    matches = (subjectEnum->def->name == patEnum->def->name &&
                              subjectEnum->tag == patEnum->tag);
                } else if (std::holds_alternative<std::shared_ptr<callable::MacCallable>>(patternVal)) {
                    // Data variant constructor — check tag match via constructor name
                    auto fn = std::get<std::shared_ptr<callable::MacCallable>>(patternVal);
                    auto ctor = dynamic_cast<callable::EnumConstructor*>(fn.get());
                    if (ctor && subjectEnum->def->name == ctor->enumName() &&
                        subjectEnum->tag == ctor->variantName()) {
                        matches = true;
                    }
                }

                if (matches) {
                    // Bind field values to variables in a new scope
                    auto scope = std::make_shared<environment::Environment>(env);
                    auto prevEnv = env;
                    env = scope;
                    for (size_t i = 0; i < arm.bindings.size() && i < subjectEnum->fieldValues.size(); i++) {
                        auto bindName = std::get<std::string>(arm.bindings[i].lexeme);
                        env->define(bindName, subjectEnum->fieldValues[i]);
                    }
                    auto result = evaluate(arm.result);
                    env = prevEnv;
                    return result;
                }
                continue;
            }
        }

        // Regular value matching (existing behavior)
        auto pattern = evaluate(arm.pattern);
        if (isEqual(subject, pattern)) {
            return evaluate(arm.result);
        }
    }

    return std::monostate{};
}
```

Note: `EnumConstructor` needs public accessors `enumName()` and `variantName()` — add these getter methods.

```cpp
MV visitMatchExpr(expr::MatchExpr<MV>* expr) override {
    resolveExpr(expr->subject);
    for (auto& arm : expr->arms) {
        if (arm.pattern) resolveExpr(arm.pattern);
        // Bindings are defined in the arm's scope — don't resolve them as references
        resolveExpr(arm.result);
    }
    return std::monostate{};
}
```

In `include/AnalyzerWalk.h`, extend the `MatchExpr` handling. After analyzing all arms, check if the subject is an enum type and all variants are covered:

```cpp
} else if (auto* p = dynamic_cast<expr::MatchExpr<MV>*>(e)) {
    analyzeExpr(p->subject.get());
    bool hasWildcard = false;
    std::vector<std::string> coveredVariants;

    for (auto& arm : p->arms) {
        if (!arm.pattern) {
            hasWildcard = true;
        } else {
            analyzeExpr(arm.pattern.get());
            // Try to extract variant name from Get expression (Enum.Variant)
            if (auto* get = dynamic_cast<expr::Get<MV>*>(arm.pattern.get())) {
                auto varName = tokName(get->name);
                coveredVariants.push_back(varName);
            }
        }
        analyzeExpr(arm.result.get());
    }

    // Check exhaustiveness if subject type is a known enum
    if (!hasWildcard) {
        auto subjectType = inferType(p->subject.get());
        // Check if subjectType matches a known enum
        for (auto& [enumName, variants] : enumVariants) {
            if (subjectType == enumName || subjectType == "enum " + enumName) {
                for (auto& v : variants) {
                    bool covered = false;
                    for (auto& cv : coveredVariants) {
                        if (cv == v) { covered = true; break; }
                    }
                    if (!covered) {
                        addDiagnostic(p->keyword,
                            "Non-exhaustive match — missing " + enumName + "." + v, "warning");
                    }
                }
            }
        }
    }

    if (p->keyword.line > 0 && currentSource == "user") {
        result.semanticTokens.push_back({
            p->keyword.line, safeCol(p->keyword),
            5, "keyword", currentSource});
    }
}
```

```mac
// Result pattern — error handling
enum Result { Ok(value), Error(message) }

fun divide(a, b) {
    if (b == 0) return Result.Error("division by zero");
    return Result.Ok(a / b);
}

val r1 = match divide(10, 2) {
    Result.Ok(v) -> "result: {v}"
    Result.Error(e) -> "error: {e}"
};
print r1;                             // expect: result: 5

val r2 = match divide(10, 0) {
    Result.Ok(v) -> "result: {v}"
    Result.Error(e) -> "error: {e}"
};
print r2;                             // expect: error: division by zero

// Option pattern
enum Option { Some(value), None }

fun find_first(arr, pred) {
    for (var item in arr) {
        if (pred(item)) return Option.Some(item);
    }
    return Option.None;
}

val found = match find_first([1, 2, 3, 4], (x) -> x > 2) {
    Option.Some(v) -> "found: {v}"
    Option.None -> "not found"
};
print found;                          // expect: found: 3

val missing = match find_first([1, 2], (x) -> x > 10) {
    Option.Some(v) -> "found: {v}"
    Option.None -> "not found"
};
print missing;                        // expect: not found

print "enum result ok";               // expect: enum result ok
```
